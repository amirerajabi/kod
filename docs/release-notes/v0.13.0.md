**Install**
- **Windows x64:** `Kod-Setup-0.13.0.exe`. Kod 0.2.x to 0.12.x update themselves to this version.
- **macOS (Apple silicon):** `Kod-0.13.0-mac-arm64.dmg` (ad-hoc signed: right-click › Open the first time).
- **Linux x64:** `Kod-0.13.0-linux-x86_64.AppImage`.

Kod needs the **.NET 10 SDK** on PATH.

**The debugger, more like Rider**
- **Value popup**: while paused, hover a variable, a member chain like `person.Name`, or a selection to see its value. Expand objects as a tree, open collections and long strings with **View**, and double-click a child's value to set it. Variables show their value instead of the code tooltip while paused; methods and types still show their tooltip.
- **Inline values**: the values of the locals appear after each line of the current method, up to the paused line, and update on every step.
- **Run to Cursor from the line numbers**: while paused, hover a line number to turn it into a green arrow and click it to run to that line. Like Rider, it still stops at breakpoints on the way.
