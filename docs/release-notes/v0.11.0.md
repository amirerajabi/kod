**Install**
- **Windows x64:** `Kod-Setup-0.11.0.exe`. Kod 0.2.x to 0.10.x update themselves to this version.
- **macOS (Apple silicon):** `Kod-0.11.0-mac-arm64.dmg` (ad-hoc signed: right-click › Open the first time).
- **Linux x64:** `Kod-0.11.0-linux-x86_64.AppImage`.

Kod needs the **.NET 10 SDK** on PATH.

**New: Show Usages, like Rider**
- **Ctrl+Alt+F7**, the editor's right-click menu, or a click on a Code Vision "N usages" opens a popup at the caret with every usage of the symbol.
- Each row shows the usage type, the line with the name highlighted, the member it is in and `File.cs:line`.
- Type to filter. ↑↓, PageUp/PageDown and Enter go to a usage; Esc clears the filter, then closes.
- The toolbar shows or hides reads, writes and declarations, adds a preview of the code around the usage, and moves the results to the Find window.
- A symbol with a single usage goes straight to it.

**New: the Find Usages window, like Rider**
- **Alt+F7** lists the usages in a tree: usage type, project, file. Grouping by usage type, project, directory, file and member can each be switched on or off, and Kod remembers your choice.
- Usage types follow Rider: Declaration, Invocation, New instance creation, Read access, Write access, Read/write access, Type usage, Usage in typeof, Base type, Attribute usage, Usage in nameof, Usage in import.
- Read and write filters, a source preview beside the tree, Expand/Collapse all, Previous/Next Occurrence (Ctrl+Alt+Up/Down) and Rerun.
- **Pin tab** keeps a search: the next one opens in a tab beside it.
