**Install**
- **Windows x64:** `Kod-Setup-0.8.0.exe`. Kod 0.2.x to 0.7.x update themselves to this version.
- **macOS (Apple silicon):** `Kod-0.8.0-mac-arm64.dmg` (ad-hoc signed: right-click › Open the first time).
- **Linux x64:** `Kod-0.8.0-linux-x86_64.AppImage`.

Kod needs the **.NET 10 SDK** on PATH.

**New: memory indicator and the Memory window**
- The status bar shows how much memory Kod uses, with the engine's share of its limit. Click it for the Memory window: where the memory goes (the code engine, the window, graphics and other processes), a live graph, and the engine's documents, caches and garbage collections.
- **Free memory** empties the caches and gives memory back to the system. **Deep clean** also drops Roslyn's compilations; they are rebuilt as you work.

**New: Kod keeps itself small**
- After you have been idle for a while, or the window has been hidden for a minute, Kod gives memory back to the system.
- Above its limit (Settings › Memory & performance, default a quarter of your RAM) the engine drops its caches and compilations, then warns you and suggests unloading projects.
- Only the last 8 finished outputs per Build and Run window are kept (adjustable). Files opened only for a preview are released.

**New: Unload / Load Project**
- Right-click a project in the Explorer, or use the Memory window: an unloaded project leaves the solution (no completion, analysis or Find Usages inside it). Projects that use it compile against its last build. Kod remembers your choice per folder.
- File › Unload All Projects but the Run Configuration, and Load All Projects.

**New: Power Save Mode**
- File › Power Save Mode turns off inlay hints, Code Vision, inspections, inline blame, the minimap and the automatic completion popup (Ctrl+Space still completes).

**Faster**
- Completion sends the editor only the best 400 matches for what you typed, instead of every one of the 10,000+ items Roslyn offers. Each further keystroke in the same word takes milliseconds instead of seconds. The `using` for a type from another namespace is added when you pick it.
- A typing round (errors, completion, quick fixes, colouring) went from about 1.4 s to 0.26 s on Kod's own engine.
- Fixed memory leaks: old quick-fix snapshots and analyzer sets were kept forever.
