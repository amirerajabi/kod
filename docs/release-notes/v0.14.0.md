**Install**
- **Windows x64:** `Kod-Setup-0.14.0.exe`. Kod 0.2.x to 0.13.x update themselves to this version.
- **macOS (Apple silicon):** `Kod-0.14.0-mac-arm64.dmg` (ad-hoc signed: right-click › Open the first time).
- **Linux x64:** `Kod-0.14.0-linux-x86_64.AppImage`.

Kod needs the **.NET 10 SDK** on PATH.

**New: Copy/Paste Special, like Rider** (Edit › Copy/Paste Special)
- **Copy Path/Reference…** (**Ctrl+Alt+Shift+C**) opens a popup at the caret. Each choice shows what it copies:
  - the absolute path, the file name, or the path from the solution or repository root
  - the reference, like `MyApp.Orders.OrderService.Submit`
  - the file and line
  - a GitHub or GitLab link to the selected lines at the current commit
- **Copy Paths** (**Ctrl+Shift+C**) copies the file's path. **Copy Reference** copies the symbol's full name, or the file and line when the caret isn't on a symbol.
- **Copy as Plain Text** copies without colours. **Copy as Rich Text** copies with the editor's syntax colours, for documents and mail.
- **Paste from History…** (**Ctrl+Shift+V**) lists everything you copied or cut in Kod, newest first, kept across restarts. Type to filter, then Enter to paste or Delete to forget an entry.
- **Paste as Plain Text** (**Ctrl+Alt+Shift+V**) pastes exactly what was copied, without re-indenting.

**New: the browser opens after run, like Rider**
- When a web app starts listening, Kod opens it in the browser, under both Run and Debug.
- By default this follows the launch profile's `launchBrowser` and `launchUrl` in launchSettings.json.
- Run › Edit Configurations has a new **After launch** setting: follow the launch profile, always open, or never open. You can also choose the page, like `swagger` or a full URL.
- It opens once per run, so a Hot Reload restart doesn't open another tab.
