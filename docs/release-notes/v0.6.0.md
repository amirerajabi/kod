**Install**
- **Windows x64:** `Kod-Setup-0.6.0.exe`. Kod 0.2.x to 0.5.x update themselves to this version.
- **macOS (Apple silicon):** `Kod-0.6.0-mac-arm64.dmg` (ad-hoc signed: right-click › Open the first time).
- **Linux x64:** `Kod-0.6.0-linux-x86_64.AppImage`.

Kod needs the **.NET 10 SDK** on PATH.

**New: Refactor This** (Ctrl+Shift+R)
- A menu at the caret with every refactoring that applies there: Rename, Change Signature, Safe Delete, Extract Interface and all of Roslyn's refactorings.
- **Change Signature** (Ctrl+F6): add, remove, reorder and rename parameters, set default values, and give new parameters a value for existing calls. Calls, overrides and interface implementations are all updated.
- **Safe Delete** (Alt+Delete): lists the remaining usages first. Deleting a parameter also removes it from every call; a file left without types is deleted too.
- **Extract Interface**: pick the public members, and Kod creates `IName.cs` and adds the interface to the class.

**New: inlay hints and Code Vision**
- Parameter names before literal arguments (`Add(a: 1, b: 2)`) and the inferred types of `var`, `foreach` variables and lambda parameters.
- Above types and members: how many usages, implementations, inheritors or overrides they have. Click to find usages or jump to the implementations.
- Turn either off in Settings › Editor › Code insight.

**New: Call Hierarchy and Type Hierarchy**
- Ctrl+Alt+H shows who calls a method (or what it calls); Ctrl+H shows a type's inheritors (or its base types), in the new Hierarchy tool window.

**New: postfix templates and Surround With**
- Type `.` after an expression for `.if`, `.else`, `.not`, `.null`, `.notnull`, `.foreach`, `.for`, `.var`, `.return`, `.await`, `.using`, `.switch`, `.cast`, `.new` and more, offered by what the expression is.
- Ctrl+Alt+T wraps the selected lines in if, while, for / foreach, try / catch / finally, using, lock, #region or a block, or a selection inside a line in parentheses, a negation, a cast or quotes.

**New: code inspections**
- While you type, the editor shows Roslyn's IDE inspections (unused members and parameters, redundant code, simplifications, style) and your projects' own analyzers, following .editorconfig. Turn it off in Settings › Editor › Code insight.
- Code › Inspect Code runs every inspection on the whole solution, in the new Inspections tool window, with **Fix all** per inspection.
- Alt+Enter also offers "Fix all in file / solution" and "Disable with #pragma".
- Code Cleanup (Ctrl+Alt+Shift+L) removes redundant code, applies the syntax style, sorts usings and reformats the file.

**New: structural navigation**
- Navigate To (Ctrl+Shift+G), Go to Type Declaration (Ctrl+Shift+F11), Base Symbols (Alt+Home), Derived Symbols (Alt+End), Related Files (Ctrl+Alt+Home).
- Next / previous member (Alt+Down / Alt+Up), Back / Forward across files (Ctrl+Alt+Left / Right).
- Recent Files (Ctrl+E) and Recent Locations (Ctrl+Shift+E).

**Changed: shortcuts** (Rider keymap)
- Ctrl+H is Type Hierarchy; Find and Replace moved to Ctrl+R.
- Alt+Up / Alt+Down move between members; Ctrl+Shift+Up / Down still move lines.
