**Install**
- **Windows x64:** `Kod-Setup-0.3.0.exe`. Kod 0.2.x updates itself to this version.
- **macOS (Apple silicon):** `Kod-0.3.0-mac-arm64.dmg` (ad-hoc signed: right-click › Open the first time).
- **Linux x64:** `Kod-0.3.0-linux-x86_64.AppImage`.

Kod needs the **.NET 10 SDK** on PATH, and Git for the Git features.

**New: Git (Rider's VCS tools)**
- **Commit** window (Alt+0): changed and unversioned files with check boxes, commit message, Amend, Commit / Commit and Push, Rollback, Stage / Unstage, Show Diff.
- **Diff tabs**: side-by-side or unified, previous / next change; the working side stays editable.
- **Gutter change markers**: added / modified / deleted lines since HEAD, live while you type.
- **Annotate** (git blame) in the editor; Git status colours on file names in the explorer and the tabs.
- **Branches** popup (status bar, top bar, Ctrl+Shift+`): checkout local or remote branches, new branch, delete, Update Project (pull), Push (Ctrl+Shift+K), Fetch.
- **Git log** window (Alt+9): history of all branches with refs, filter, commit details and per-file diffs.
- Create a Git repository from the Commit window.

**New: Unit tests (Rider's Unit Tests window)**
- Tests found by Roslyn in xUnit, NUnit and MSTest projects, without building first: project › namespace › class › test.
- Run all, run failed, run a namespace, class or test; data rows of theories and test cases; filter and "failed only".
- Failure details with the assertion message, a stack trace that links to the source, and the test output.
- **Run test** / **Run all tests** code lenses in the editor, with ✔ / ✘ from the last run. Ctrl+U Ctrl+L runs all, Ctrl+U Ctrl+R the tests in the current file.
