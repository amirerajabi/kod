**Install**
- **Windows x64:** `Kod-Setup-0.10.0.exe`. Kod 0.2.x to 0.9.x update themselves to this version.
- **macOS (Apple silicon):** `Kod-0.10.0-mac-arm64.dmg` (ad-hoc signed: right-click › Open the first time).
- **Linux x64:** `Kod-0.10.0-linux-x86_64.AppImage`.

Kod needs the **.NET 10 SDK** on PATH.

**New: Auto Save like Rider, on by default**
- Files are saved when Kod loses focus, when you switch or close a tab, before build, run, test, debug and Git, after 15 seconds without typing or clicking, and when Kod quits. Closing a tab no longer asks to save.
- If you left Auto Save at the old default (off), it is now on. If you picked a mode yourself, Kod keeps it. Settings › General has the idle time and the other modes.

**New: history like Rider**
- **Project and folder history** (Explorer › Local History, or File › Local History): every change across files, newest first. Files saved together form one change. Pick a change to see what it did to each file, then revert the whole change or one file.
- **Show History for Selection** (right-click selected lines): only the versions in which those lines changed.
- **Recent Changes** (Alt+Shift+C): the latest changes at a glance.
- When another program changes a file you edited in Kod (a git checkout, a formatter), Local History keeps that version too. Every commit and every revert puts a label in the project history, and you can add your own.

**New: tool windows on the left, like Rider**
- A stripe of tool window buttons on the left edge replaces the tab rows. The side panel windows are at the top, the bottom panel ones at the bottom, and each button opens or hides its window.
- Only the everyday windows are on the stripe at first. ⋯ More tool windows (or View › Tool Windows) opens any other one and chooses which stay on the stripe. Right-click a button to remove it.
- The buttons show live state: a spinner while building or testing, the error count, the coverage.
