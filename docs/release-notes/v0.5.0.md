**Install**
- **Windows x64:** `Kod-Setup-0.5.0.exe`. Kod 0.2.x to 0.4.x update themselves to this version.
- **macOS (Apple silicon):** `Kod-0.5.0-mac-arm64.dmg` (ad-hoc signed: right-click › Open the first time).
- **Linux x64:** `Kod-0.5.0-linux-x86_64.AppImage`.

Kod needs the **.NET 10 SDK** on PATH.

**New: a real terminal** (Alt+F12)
- Type your command right at the prompt, as in Rider: a pseudo console (ConPTY on Windows, a pty on macOS / Linux) drawn by xterm.js.
- PowerShell (pwsh, else Windows PowerShell), zsh or bash with their own line editing, history, Tab completion and colours.
- Ctrl+C interrupts (copies when text is selected), Ctrl+V pastes; the terminal keeps Ctrl+letter keys for the shell.
- Several terminal tabs; scrollback survives hiding the tool window; follows the app theme.

**New: Show All Files in the explorer**
- The eye button in the Explorer toolbar (or Settings › General) also lists bin, obj, .git, .vs and node_modules, dimmed like Rider's excluded folders.

**New: inline blame (GitToolBox)**
- The caret line shows who changed it last, how long ago and the commit message; hover for the date and hash. Lines you have not committed say so.
- Turn it off in Settings › Editor or with Git › Toggle Inline Blame.

**New: Git remotes**
- Git › Manage Remotes (also in the branches popup): add, rename, change the URL of and remove remotes.
- Pushing a repository with no remote opens the dialog instead of failing.
