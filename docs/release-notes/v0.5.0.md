**Install**
- **Windows x64:** `Kod-Setup-0.5.0.exe`. Kod 0.2.x to 0.4.x update themselves to this version.
- **macOS (Apple silicon):** `Kod-0.5.0-mac-arm64.dmg` (ad-hoc signed: right-click › Open the first time).
- **Linux x64:** `Kod-0.5.0-linux-x86_64.AppImage`.

Kod needs the **.NET 10 SDK** on PATH.

**New: AI Assistant** (Alt+2, or the ✨ button) — Claude, ChatGPT, GLM, Gemini and more
- A chat window on the right, like Rider's AI Assistant. Providers: **Claude** (Anthropic, through the official Anthropic SDK), **ChatGPT** (OpenAI), **GLM** (Zhipu bigmodel.cn or Z.ai), **Gemini**, **DeepSeek**, **Mistral**, **Grok**, **Qwen**, **OpenRouter**, local **Ollama** / **LM Studio**, or any OpenAI-compatible server.
- **Agent mode**: the assistant reads, lists and searches your workspace, edits files and runs commands (dotnet build, dotnet test), and asks you before every edit or command (Allow / Always / Deny). **Auto** mode does not ask; **Chat** mode only answers.
- Streaming answers with Markdown and coloured code blocks (Copy, Insert at caret); Claude's thinking summary; the current file and selection go along with your message.
- Right-click in the editor or use the AI menu: Explain, Find and Fix Problems, Write Unit Tests, Add Documentation Comments.
- Settings › AI Assistant: provider, model (Fetch models lists what your key can use), base URL, effort for Claude. API keys are encrypted by your operating system's keychain and never written to Kod's settings.
- Claude requests use adaptive thinking, prompt caching and server-side fallback when a model declines.

**New: fonts**
- Settings › Appearance › Fonts: pick the editor font from your installed fonts, and set the UI font and size and the terminal font and size.

**Changed: run configurations**
- The run configuration list shows only projects that can run (class libraries and test projects are left out).

**New: a real terminal** (Alt+F12)
- Type your command right at the prompt, as in Rider: a pseudo console (ConPTY on Windows, a pty on macOS / Linux) drawn by xterm.js.
- PowerShell (pwsh, else Windows PowerShell), zsh or bash with their own line editing, history, Tab completion and colours.
- Ctrl+C interrupts (copies when text is selected), Ctrl+V pastes; the terminal keeps Ctrl+letter keys for the shell.
- Several terminal tabs; scrollback survives hiding the tool window; follows the app theme.

**New: Show All Files in the explorer**
- The eye button in the Explorer toolbar (or Settings › General) also lists bin, obj, .git, .vs and node_modules, dimmed like Rider's excluded folders.

**New: inline blame (GitToolBox)**
- The caret line shows who changed it last, how long ago and the commit message; hover for the date and hash. Lines you have not committed say so.
- Turn it off in Settings › Editor or with Git › Toggle Inline Blame.

**New: Git remotes**
- Git › Manage Remotes (also in the branches popup): add, rename, change the URL of and remove remotes.
- Pushing a repository with no remote opens the dialog instead of failing.
