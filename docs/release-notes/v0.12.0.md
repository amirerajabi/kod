**Install**
- **Windows x64:** `Kod-Setup-0.12.0.exe`. Kod 0.2.x to 0.11.x update themselves to this version.
- **macOS (Apple silicon):** `Kod-0.12.0-mac-arm64.dmg` (ad-hoc signed: right-click › Open the first time).
- **Linux x64:** `Kod-0.12.0-linux-x86_64.AppImage`.

Kod needs the **.NET 10 SDK** on PATH.

**New: Run/Debug Configurations, like Rider**
- **Alt+Shift+F10**, or the top bar's configuration picker › **Edit Configurations…**.
- Every runnable project has a configuration. Add your own with a launch profile from launchSettings.json (or none), program arguments, environment variables and a working directory.
- **Compound** configurations start several projects at once. Debugging one debugs its first project and runs the others.

**New: Hot Reload**
- Tick **Hot Reload** in a configuration: the app runs under `dotnet watch`, and every saved edit is applied to it while it runs.
- An edit Hot Reload cannot apply restarts the app. Kod tells you which one happened.

**New in the debugger**
- **Breakpoint properties**: right-click a breakpoint, or press **Ctrl+Shift+F8**, for a condition, a hit count (the Nth hit, from the Nth, every Nth), a log message with `{expressions}`, suspend or not, enable / disable, and remove once hit.
- **Logpoints**: Shift+click the gutter. They print to the Debug console without pausing.
- **Break on exceptions**: user-unhandled or all thrown (the ⚡ button in the Debug window, or Run › Break on Exceptions). The pause shows the exception's type and message.
- **Attach to Process** (**Ctrl+Alt+F5**): pick any running .NET program. Stopping detaches and leaves it running.
- **Run to Cursor** (**Alt+F9**), also on the gutter's right-click menu while paused.
- **Set Value**: double-click a variable's value while paused and type an expression.

**New: Pull Requests (GitHub)**
- A Pull Requests tool window: open, closed or all, and yours. It uses your `gh` sign-in, `GITHUB_TOKEN`, or a token you enter.
- Details with checks, reviews and comments; click a changed file to see its diff.
- Checkout, **Create Pull Request…** (Git menu), comment, review (approve, request changes, comment) and merge (merge, squash, rebase).

**New: Generate, like Rider**
- **Alt+Insert** in the C# editor (also the right-click menu and Code › Generate) generates a constructor (with null checks), properties, read-only properties, equality members (IEquatable, GetHashCode, == and !=), ToString, overriding members, missing members and the dispose pattern.
- Alt+Insert outside the editor still creates a new class.

**New refactorings** (in Refactor This, Ctrl+Shift+R)
- **Move Type to Another File / Folder**, updating the namespace to match the folder.
- **Pull Members Up** to a base class or interface, and **Push Members Down** to derived classes.
- **Inline** (**Ctrl+Alt+N**): a local variable, a constant or field, a method at every call or only this one.
- **Extract Class**: the chosen members move to a new class, which the original then uses through a field.

**New: Project Properties**
- Right-click a project in the Explorer › **Properties…**, or File › Project Properties.
- Application, Build, Package and References pages edit the .csproj in place, keeping its comments and layout. Values from Directory.Build.props show as inherited.
- Right-click the solution to add an existing project or remove one.
