**Install**
- **Windows x64:** `Kod-Setup-0.9.0.exe`. Kod 0.2.x to 0.8.x update themselves to this version.
- **macOS (Apple silicon):** `Kod-0.9.0-mac-arm64.dmg` (ad-hoc signed: right-click › Open the first time).
- **Linux x64:** `Kod-0.9.0-linux-x86_64.AppImage`.

Kod needs the **.NET 10 SDK** on PATH.

**New: HTTP Client**
- `.http` and `.rest` files (Rider's and Visual Studio's format): click ▶ Send request above a request, or press Ctrl+Enter in it. Responses open in the HTTP Client window, with formatted JSON or XML, images, headers, timing and size.
- Variables (`@name = value`), environments from `http-client.env.json`, `{{$guid}}`, `{{$timestamp}}` and `{{$randomInt}}`, bodies from files, Copy as cURL, and completion.
- Right-click a web project › Generate HTTP Requests writes a request for every endpoint (minimal APIs, route groups and controllers).

**New: EF Core window**
- Choose the migrations project, the startup project and the DbContext. Each migration shows whether the database has it.
- Add or remove migrations, update the database to the latest or to any migration, drop it, and generate the SQL script.
- Scaffold a DbContext from a Database panel data source. The connection string stays out of the command line and out of the generated code.

**New: code coverage**
- Run with Coverage (the shield button, or right-click a test): green, red and yellow bars in the editor gutter for covered, uncovered and partly covered lines. The Coverage window shows the figures per assembly and per file.

**New: debugger visualizers**
- A View link in Variables opens lists, arrays, dictionaries and DataTables as a grid you can sort, filter and copy as CSV or TSV. Long strings open in a Text, JSON, XML or HTML viewer.

**New: live diagnostics while debugging**
- Debug window › Diagnostics charts the program's CPU, memory and GC heap, collections, allocations, exceptions and thread pool, live. It also lists every exception and garbage collection as it happens.

**New: AI inline completions**
- Grey suggestions as you type, from your AI provider with a fast model (Settings › AI; off by default). Tab accepts, Ctrl+→ takes a word, Alt+\ asks for one.
