**Install**
- **Windows x64:** `Kod-Setup-0.4.0.exe`. Kod 0.2.x and 0.3.x update themselves to this version.
- **macOS (Apple silicon):** `Kod-0.4.0-mac-arm64.dmg` (ad-hoc signed: right-click › Open the first time).
- **Linux x64:** `Kod-0.4.0-linux-x86_64.AppImage`.

Kod needs the **.NET 10 SDK** on PATH.

**New: NuGet tool window (Rider's NuGet window)** — Alt+Shift+7, or View › NuGet Packages
- **Browse / Installed / Updates** for the whole solution; search every enabled v3 feed or pick one; prerelease toggle.
- **Package details**: all versions, description, authors, license, project and nuget.org links, downloads, publish date, tags, dependencies per target framework, and deprecation / vulnerability warnings.
- **Projects**: every project with its installed version and install (+), upgrade / change (↑) and remove (−) buttons, plus "Install to all" and "Set version everywhere"; **Update all** in the Updates view.
- Central package management: versions from `Directory.Packages.props` are shown as central.
- **Sources** tab: the feeds your NuGet.Config files define, enable / disable them; **Restore**.
- The list refreshes by itself when a project file changes.
