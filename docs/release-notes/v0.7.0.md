**Install**
- **Windows x64:** `Kod-Setup-0.7.0.exe`. Kod 0.2.x to 0.6.x update themselves to this version.
- **macOS (Apple silicon):** `Kod-0.7.0-mac-arm64.dmg` (ad-hoc signed: right-click › Open the first time).
- **Linux x64:** `Kod-0.7.0-linux-x86_64.AppImage`.

Kod needs the **.NET 10 SDK** on PATH.

**New: Local History**
- Every save, delete, refactoring and AI Assistant edit keeps a revision of the file, Git or not, for 30 days.
- Right-click a tab › Show Local History (or File › Local History): every revision diffed against the current text, with Revert and Put Label.

**New: bookmarks and the TODO window**
- F11 toggles a bookmark on the caret line; Ctrl+Shift+1…9 sets a numbered one and Ctrl+1…9 jumps back to it; Ctrl+F11 uses a letter. Bookmarks move with your edits; Shift+F11 lists them.
- The TODO window (Alt+Shift+6) lists the TODO, FIXME, HACK, BUG and NOTE comments of the project or the current file.

**New: more Git**
- **Merge conflicts**: Resolve… lists the conflicted files with Accept Yours, Accept Theirs and Merge…, a three-way merge tool (yours, the result with Accept actions per conflict, theirs). Continue, Skip and Abort finish a stopped merge, rebase or cherry-pick.
- **From the Git log**: Cherry-Pick, Revert Commit, Reset Current Branch to Here, Checkout Revision, New Branch and **Interactively Rebase from Here** (reorder, reword, edit, squash, fixup, drop).
- **Stash and Shelf**: stash or shelve changes and bring them back later, in the Git window's Stashes and Shelf tabs.
- **Changelists** in the Commit window, and **partial commits**: expand a file and pick the hunks or single lines to commit.

**New: Database**
- The Database panel (Alt+Shift+D) connects to SQL Server, PostgreSQL, MySQL / MariaDB and SQLite, or imports the connection strings of your appsettings.json. Passwords are kept by your operating system's keychain.
- Browse schemas, tables, views and columns; double-click a table for its first 100 rows.
- SQL consoles: Ctrl+Enter runs the selection or the statement at the caret; results in a grid you can copy as TSV or CSV.
- SQL completion from the schema in consoles and inside C# strings: FromSqlRaw, ExecuteSqlRaw, SqlQuery, Dapper's Query and Execute.

**New: Docker**
- The Services window (Alt+Shift+8): Docker Compose services, containers and images. Start, stop, restart, remove, follow the log, or open a terminal inside a container; compose up and down.
- Run › Run in Docker builds the project's Dockerfile and runs it; Run › Debug in Docker runs your build inside the Dockerfile's base stage with the debugger attached. Docker Desktop (or another Docker engine) must be running.

**Changed**
- With many tool windows, inactive tabs show only their icon when space is short.
- The inline blame at the end of the caret line shows reliably.
