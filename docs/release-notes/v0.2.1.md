**Install**
- **Windows x64:** `Kod-Setup-0.2.1.exe`. Kod 0.2.0 updates itself to this version (Settings › Updates, or wait for the status bar chip).
- **macOS (Apple silicon):** `Kod-0.2.1-mac-arm64.dmg`. Ad-hoc signed: the first time, right-click Kod › Open. New versions are announced in the app (download from the release page).
- **Linux x64:** `Kod-0.2.1-linux-x86_64.AppImage` (`chmod +x`, then run it).

Kod needs the **.NET 10 SDK** (`dotnet` on PATH) on every platform. The Windows installer is not code-signed, so SmartScreen may warn ("More info" › "Run anyway").

**New**
- Releases are built and published by GitHub Actions (CI on every push and pull request; a `v*` tag builds Windows, macOS and Linux on their own runners and publishes the release with the update metadata).
- First macOS and Linux builds.
